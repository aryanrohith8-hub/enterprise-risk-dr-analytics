# Enterprise Risk & Disaster Recovery Analytics Platform

## 1. Project Overview

This project develops an enterprise analytics platform
to evaluate application risk exposure, disaster recovery
readiness and business continuity performance.

The platform uses synthetic enterprise data to generate
actionable insights for management and risk teams.

## 2. Project Objectives

- Evaluate application-level risk exposure.
- Assess disaster recovery readiness.
- Identify RTO and RPO violations.
- Analyse historical risk trends.
- Monitor recurring DR test failures.
- Identify applications requiring remediation.
- Develop interactive management dashboards.

## 3. Data Sources

The platform consists of five simulated datasets:

1. Business Units
2. Applications
3. Risk Assessments
4. DR Assessments
5. Incidents

All datasets will contain synthetic data created
specifically for this project.

No confidential client or organisational information
will be used.

## 4. Technology Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQLite
- SQLAlchemy
- Power BI
- Git and GitHub

## 5. Business Questions

- Which business units have the highest risk exposure?
- Which critical applications have inadequate DR readiness?
- Which applications exceed their recovery objectives?
- Which applications repeatedly fail DR tests?
- How are risk scores changing over time?
- Which applications should be prioritised for remediation?

## 6. Project Scope

The project covers:

- Synthetic data generation
- Data validation and cleaning
- Exploratory data analysis
- Risk and DR analytics
- SQL database development
- Power BI dashboard development
- Testing and documentation

## 7. Business Assumptions

Risk scores will range from 1 to 10.

- Low: 1-3
- Medium: 4-6
- High: 7-8
- Critical: 9-10

Recovery objectives will be defined according
to application criticality.

All project thresholds are illustrative assumptions.
They do not represent regulatory requirements.
